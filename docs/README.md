# 词根树文档索引

> 文档版本/日期：v1.0 / 2026-11-25
> 真相源对照：文件与实现以当前仓库源码、`package.json` 及测试为准；本文是 `docs/` 的唯一正式索引（纯中文单语）。
> 状态：定稿；新增、移动或废弃正式文档必须在同一变更中同步更新本索引。

## 1. 必读顺序

进行任何非平凡改动前，按以下顺序阅读对应文档：

1. [站点工程架构](app/architecture.md) - 了解 SvelteKit 2 + Svelte 5（Runes）静态架构、路由地图、数据分片链路与全局 Store 所有权。
2. [变更工作流](spec/change-workflow.md) - 确认变更分级、改前防误撤核对、按 `git diff` 定向验证与交付审计。
3. [文档结构与命名规范](spec/doc-convention.md) - 新建规范或沉淀决策记录（ADR）前阅读。
4. [UI 视觉与交互规范入口](ui/README.md) - 改动任何可见样式、主题、动效、滚动、字体、快捷键或学习交互前必读。

历史已确认的决策位于 `docs/decisions/implemented/`，**优先级高于新提出的“顺手优化”建议**。如确需推翻旧决策，必须在修改代码前核对对应 ADR 并记录新决策或修订原决策。
